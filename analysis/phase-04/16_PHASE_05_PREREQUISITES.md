# Phase 5 Prerequisites

Phase 5 may begin only after:

- explicit user review,
- canonical archive or approved mirror decision,
- review of all Phase 1–4 reports,
- Windows build/VM authorization,
- hardware evidence and rollback approval,
- service account decision,
- dependency and signing decision,
- confirmation that no implementation milestone is started prematurely.

Phase 5 must not assume hardware writes are safe.
